# 📄 ANJANAM PROJECT – FULL SYSTEM SETUP GUIDE (WINDOWS)

## 🧩 1. Install Core Tools

### ✅ Flutter SDK

1. Download Flutter SDK (Windows)
2. Extract to:

```
C:\src\flutter
```

3. Add to PATH:

```
C:\src\flutter\bin
```

4. Verify:

```
flutter doctor
```

---

### ✅ Node.js (LTS)

1. Install from official site
2. Verify:

```
node -v
npm -v
```

---

### ✅ Git

1. Install Git
2. Verify:

```
git --version
```

---

## 📱 2. Android Setup

### ✅ Install Android Studio

Install with:

* Android SDK
* SDK Platform Tools
* Command-line Tools

---

### ✅ Install Required SDK Components

Open:

```
Android Studio → More Actions → SDK Manager → SDK Tools
```

Enable:

* Android SDK Command-line Tools (latest)
* Android SDK Platform-Tools
* Android SDK Build-Tools

---

### ✅ Accept Licenses

```
flutter doctor --android-licenses
```

Press `y` for all prompts

---

### ✅ Verify

```
flutter doctor
```

---

## 🔧 3. Backend & CLI Tools

### ✅ Supabase CLI (Manual Install)

1. Download:

```
supabase_windows_amd64.tar.gz
```

2. Extract → get:

```
supabase.exe
```

3. Move to:

```
C:\supabase
```

4. Add to PATH:

```
C:\supabase
```

5. Verify:

```
supabase --version
```

---

### ✅ Firebase CLI

Install:

```
npm install -g firebase-tools
```

---

### ⚠️ Fix PowerShell Execution Policy

Run PowerShell as Administrator:

```
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

---

### ✅ Login Firebase

```
firebase login
```

(If PowerShell fails, use CMD or:)

```
firebase.cmd login
```

---

## 📁 4. Project Setup

Navigate to project:

```
cd D:\ANJANAM-NEW\ecommerce_app
```

Install dependencies:

```
flutter pub get
```

---

## 🔑 5. Config Files Check

Ensure these exist:

```
lib/firebase_options.dart
supabase/config.toml
.firebaserc
firebase.json
```

---

### If Firebase config missing:

```
flutterfire configure
```

---

## 🔗 6. Supabase Setup

Login:

```
supabase login
```

Link project:

```
supabase link --project-ref YOUR_PROJECT_ID
```

(Optional)

```
supabase db push
```

---

